# How to Test a Monitor for Dead Pixels
A 5-minute check for any new screen, using free browser tools from Black Test Screen (https://blacktestscreen.com/).
1. Clean the screen with a dry microfibre cloth — dust is the most common false alarm.
2. Open a full white screen and scan slowly: dead pixels show as dark dots. Tool: https://blacktestscreen.com/white-screen
3. Open a full black screen: stuck pixels glow red, green or blue, and backlight bleed shows at the edges. Tool: https://blacktestscreen.com/
4. Repeat with red, green and blue screens to test each subpixel.
5. Note the position of any fault and the colour that reveals it, then check your return window.
No downloads. Works on any monitor, laptop, tablet or TV with a browser.
